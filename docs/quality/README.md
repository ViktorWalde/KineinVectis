# Kernwerk Studio — Tooling & Quality Packs

Esta pasta reúne os documentos de política de toolchains, tooling nativo,
Quality Center e padrões profissionais de IDE (originalmente entregues como
dois pacotes: *Tooling & Quality Documentation Pack* e *Professional IDE
Standards Pack*).

Arquivos (nesta pasta):

```text
TOOLCHAIN_LAYER_POLICY.md          política: a IDE é camada visual sobre ferramentas reais
CPP_RUST_NATIVE_TOOLING.md         núcleo C/C++/Rust com tooling profissional e Qt/GTK nativo
QUALITY_CENTER_STRICT_MODES.md     Quality Center, strict modes e biblioteca visual de regras
KERNWERK_TOOLING_QUALITY_MASTER.md consolidação dos três documentos acima
PROFESSIONAL_IDE_STANDARDS.md      padrões profissionais globais (editor, workspace, LSP, debug, CI…)
```

Temas cobertos:

- C/C++/Rust primeiro; toolchains locais; camada visual inteligente;
- integração com ferramentas abertas profissionais; suporte nativo a Qt/GTK;
- Quality Center, strict modes e biblioteca visual de regras;
- zero telemetria; IA sob demanda;
- padrões de editor engine, workspace/project model, config schema,
  arquivos gerados, permissões de comandos, debug, LSP, build, segurança,
  performance, testes, CI, dependências, templates, acessibilidade,
  empacotamento, licenças e dogfooding.

Nota de precedência: estes documentos são material de planejamento/referência.
O estado real e vigente do repositório é descrito por `ContextoIA.md` (raiz),
pelos documentos numerados em `docs/` e pelo código. Ver `docs/README.md`.
